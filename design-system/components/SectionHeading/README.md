SectionHeading is a 20px bold title over a 3px rule, with an optional count chip and a right-side action.

## When to use
Settings sections (Defaults, Provider keys, Model pricing, Cost alerts) and Projects sections (Accounts, Repositories).

## What you provide
children = title, `count`, `action` (a small button), `as` (heading tag, default h2).

## Notes
Don't stack two headings without content between.

Hand-written brutalist rebuild of `app/(dashboard)/settings/page.tsx`.
