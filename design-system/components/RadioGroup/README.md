RadioGroup is a set of round-dot options where exactly one wins.

## When to use
Choosing between 2–5 visible options — e.g. the four reviewer personalities.

## What you provide
`label` (legend), `options: {value,label,disabled?}[]`, `value` / `defaultValue`, `onValueChange(value)`, `orientation`: vertical · horizontal, `name`, `disabled`.

## Notes
Intentional addition — not in the repo; added for complete form coverage.
