Textarea is the multi-line field for rules, prompts and path lists. It grows with its content, so there is no native resize grip.

## When to use
Per-repo extra review rules, ignore globs.

## What you provide
The same field props as Input (`label`, `hint`, `error`), plus `minHeight` (default 96px) and native textarea props (`value`, `onChange`, `rows`).

## Notes
Intentional addition. The repo has no textarea; it was added at the owner's request for complete form coverage.
